# 🛡️ Local File Inspector

A privacy-first, serverless web application that allows users to inspect and check files of **any size** (even 100GB+) locally inside their browser without uploading them to any server.

## ✨ Features
- **100% Client-Side:** Files are read locally using JavaScript Web Streams API.
- **No File Size Limits:** Handles massive files (ISOs, PKG, APK, EXE) without crushing browser RAM.
- **Zero Uploads:** Your privacy is fully preserved; files never leave your device.
- **Smart Hash Lookup:** Calculates SHA-256 fingerprint and queries VirusTotal API.
- **Multi-language & Themes:** Supports Arabic/English (RTL/LTR) with Dark/Light modes.
